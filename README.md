# ♠ Покер Тренажёр

Бесплатный тренажёр покерных навыков: **Texas Hold'em** и **Омаха** (классическая, 4-card и 5-card на двух досках). Без регистрации, подписок и рекламы — всё считается прямо в браузере, прогресс хранится локально.

## Что внутри

- **Симулятор раздач** — префлоп-решения по GTO-чартам позиций и постфлоп по эквити двух досок (флоп/терн/ривер), с разбором и переходом в GTO-чарт
- **Режим экзамена** — серия 5/10/20 раздач без подсказок, в конце оценка и полный разбор ответов
- **Математика** — пот-оддсы, требуемое эквити, EV-решения
- **Аутсы и эквити** — подсчёт аутсов, правило 2/4
- **Кто победил? / Какая комбинация?** — чтение борда и комбинаций (Холдем и Омаха)
- **GTO-чарты** — стол, позиция, соперники, раунд: что играть, что сбрасывать
- **Калькулятор эквити** — Холдем и Омаха, до 8 оппонентов, выбор диапазонов (Monte-Carlo)

Статистика тренировок (точность, серии, подсказки, экзамены) сохраняется в localStorage.

## Технологии

Next.js 16 (App Router, только клиентская часть) · TypeScript · Tailwind CSS · shadcn/ui · Zustand. Приложение статическое: серверная база не нужна, поэтому деплоится на любой статический хостинг.

## Локальный запуск

```bash
bun install
bun run dev        # http://localhost:3000
```

## Деплой на GitHub Pages

Приложение собирается в статику (`STATIC_EXPORT=1 next build` → `out/`) и публикуется GitHub Actions workflow'ом (`.github/workflows/deploy-pages.yml`) при каждом пуше в `main`.

1. Создайте репозиторий на GitHub (например, `poker-trainer`) и запушьте код:

   ```bash
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/poker-trainer.git
   git push -u origin main
   ```

2. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.

3. Готово: workflow соберёт и опубликует приложение на
   `https://<ВАШ_ЛОГИН>.github.io/poker-trainer/`
   (basePath подставляется автоматически из имени репозитория).

Пересобрать вручную: вкладка **Actions → Deploy to GitHub Pages → Run workflow**.

> Для приватного репозитория GitHub Pages доступен на платных планах; публичный — бесплатно.

## Альтернатива: Vercel

Vercel подхватывает Next.js без настроек: импортируйте репозиторий на [vercel.com](https://vercel.com) — деплой пройдёт автоматически (обычная сборка `next build`).
